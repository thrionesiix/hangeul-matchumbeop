# 고전문법 복습시험 — 세종어제훈민정음

[오름] 국어 · 훈민정음 언해 서문 44어절을 **어절 그림 + 4지선다**로 푸는 웹 시험지 + 강사용 대시보드

## 파일

| 파일 | 용도 |
|------|------|
| `index.html` | **학생용 시험지** (문항 내장, 이미지는 `images/` 에서 불러옴) |
| `images/w01.png` ~ `w44.png` | 훈민정음 언해 서문 어절 그림 44장 (구글폼에서 가져옴) |
| `dashboard.html` + `bank.js` | **강사용 대시보드** (학생에게 주소를 공유하지 말 것) |
| `AppsScript.gs` | 구글 시트에 결과를 쌓는 스크립트(독립 실행형, `SHEET_ID` 로 시트를 연다) |
| `shell.html` | 화면·로직 틀. `/*__ITEMS__*/` 자리에 `items.js` 가 들어간다 |
| `items.js` | 빌드 산출물(문항 은행). 직접 고치지 말 것 |
| `_sources/items_A~D.json` | **문항 원본**. 문항을 고칠 때는 이 파일을 고친다 |
| `_sources/form_items.json` | 구글폼(44단어·79문항) 원본 구조 |
| `build.py` | `_sources/items_*.json` → `items.js` → `index.html`, `bank.js` |

문항이나 화면을 고친 뒤에는 한 줄로 다시 만든다.

```bash
python build.py
```

### 2026-11-08 추가 수정 — 'ㆆ'의 기능 (학생 지적)

『학교 문법론』 p.415는 "'ㆆ'은 … 관형사형 어미 '-ㄹ' 아래서 주로 쓰여 된소리 부호의 기능을
하였다"라고만 적어 두었으나, **된소리로 바뀔 소리가 뒤에 와야** 그 기능이 나타난다.
본문의 세 자리는 환경이 서로 다르다.

| 어절 | 뒤에 오는 말 | 된소리가 되나 | 이 자리의 'ㆆ' |
|------|---------------|----------------|------------------|
| 15 홇 | 배 (평음 ㅂ) | 된다 → [홀 **빼**] | **된소리 부호** |
| 24 ᄒᆞᇙ | 노미 (비음 ㄴ) | 안 된다 | **관형사형 표시만** |
| 43 ᄒᆞᇙ | ᄯᆞᄅᆞ미니라 (이미 ㄸ) | 바꿀 것이 없다 | **관형사형 표시만** |

24번과 43번은 어절 그림이 똑같은 'ᄒᆞᇙ'이라 학생이 어느 자리인지 알 수 없었다.
**세 문항 모두 질문에 앞뒤 문맥을 넣었고**, 24·43번은 정답을 '관형사형임을 나타내는 표시'로
바꾸고 심화로 올렸다.

선생님 판단이 필요한 자리는 이제 하나다.

- **36 히ᅇᅧ의 'ㅣ'** — 사동 접미사로만 다루고 'ᅇ'의 음가는 묻지 않았다.

## 두 가지 링크

| 링크 | 용도 | 학생이 보는 것 |
|------|------|----------------|
| `index.html` (그냥 접속) | 자유 복습 | 범위·난도·문항 수를 직접 고름 |
| `index.html?fix=1&a=…&lv=…&n=…&t=…` | 선생님이 낸 시험 | 닉네임·이름만 입력하고 바로 시작 |

URL 파라미터: `fix=1` 잠금 / `a=0,3` 영역 번호(0 현대어 풀이, 1 표기 방식, 2 음운 현상, 3 사라진 글자, 4 조사·어미, 5 의미 변화) / `lv=0|1|2` / `n=20` / `t=시험 이름`.
링크는 대시보드의 **학생용 시험 링크 만들기**에서 만들면 된다.

## 진행 방식

1. 닉네임(필수) + 이름(필수) → 범위·난도·문항 수 → 시작
2. 한 문제씩: **어절 그림 → 질문 → 보기 4개**
3. 고르면 — 정답이면 바로 해설 / 오답이면 그림(`wrong.png`)이 먼저 뜨고 한 번 더 누르면 정답·해설
4. 마지막 문항 뒤 결과 화면: 점수, 문법 요소별 막대, 순위, 틀린 문항(어절 그림 포함)
5. `✏️ 틀린 문제만 다시 풀기` → 다 맞힐 때까지 반복
6. `결과 제출` → 구글 시트 기록(한 회차당 1회)

- 키보드: `1`·`2`·`3`·`4` 로 선택, `Enter`/`Space` 로 다음
- 최근에 푼 문항은 뒤로 미뤄져, 다시 풀면 다른 문제가 나온다
- 오답 그림은 `index.html` 과 같은 폴더의 `wrong.png`(없으면 기본 그림)
